# Support / 支持

## 中文

### 先检查文档

- 从源码启动、目标仓库准备和桌面运行：[README](README.md)
- 操作、架构与原生隔离：[操作与架构](docs/zh-cn/guide.md)
- 覆盖范围、验收记录与平台限制：[覆盖与验收说明](docs/zh-cn/validation.md)
- 已知变化：[更新记录](CHANGELOG.md)

### 提问与讨论

使用 [GitHub Discussions](https://github.com/TunneldeDev/TunneldeDebugger/discussions) 提问、分享配置经验或讨论尚不明确的需求。提交前请搜索已有讨论。

### 缺陷与功能请求

使用 [Issues](https://github.com/TunneldeDev/TunneldeDebugger/issues) 的 Bug 或 Feature 表单。请提供：

- 操作系统、浏览器、Node.js、pnpm、Rust/Tauri 版本；
- 运行模式：浏览器、桌面、原生模拟或真实服务；
- 相关提交或 Release 版本；
- 可复现步骤，以及经过脱敏的日志和截图。

不要公开凭据、私钥、真实主机信息或个人路径。

### 安全问题

不要在公开 Issue 中披露漏洞。请按 [安全策略](SECURITY.md) 使用 GitHub 私密安全公告。

### 响应范围

这是由维护者利用业余时间维护的开源项目，不承诺固定响应时间。Tunnelde 产品本身的问题请提交到 [Tunnelde 主仓库](https://github.com/TunneldeDev/Tunnelde/issues)。

## English

### Check the documentation first

- Source setup, target checkout and desktop launch: [README](README.en-us.md)
- Workflow, architecture and native isolation: [Guide](docs/en-us/guide.md)
- Coverage, acceptance evidence and platform limits: [Validation notes](docs/en-us/validation.md)
- Notable changes: [Changelog](CHANGELOG.md)

### Questions and discussion

Use [GitHub Discussions](https://github.com/TunneldeDev/TunneldeDebugger/discussions) for questions, setup notes or early ideas. Search existing discussions first.

### Bugs and feature requests

Use the Bug or Feature forms under [Issues](https://github.com/TunneldeDev/TunneldeDebugger/issues). Include:

- operating system, browser, Node.js, pnpm and Rust/Tauri versions;
- run mode: browser, desktop, native mock or real service;
- the relevant commit or release;
- deterministic reproduction steps and sanitized logs or screenshots.

Do not publish credentials, private keys, real host information or personal paths.

### Security

Do not disclose vulnerabilities in a public issue. Follow the [security policy](SECURITY.md) and use GitHub private vulnerability reporting.

### Response expectations

This open-source project is maintained on a best-effort basis and does not promise a fixed response time. Report defects in the Tunnelde product itself to the [upstream repository](https://github.com/TunneldeDev/Tunnelde/issues).
