## 尚需人工检查及范围

- 人工视觉结论仍待验收人逐项提交。自动原生冒烟不表示所有控件及所有参数组合都已视觉验收。
- 浏览器与原生模拟均使用生产组件；模拟终端只回显，不验证真实 shell。受控 SSH 服务也不执行系统 shell。
- 文件重命名/复制、转发启停及部分插件管理等模拟操作尚无适配，会明确报告不支持；对应真实服务场景未登记自动准备时标注限制。空、加载、错误及禁用预设只在实际适配的界面开放，其余显示 N/A。
- 外部插件仅提供审核后代码注册示例。未运行第三方插件代码，未测试外部插件的全部行为。
- 截图为 macOS 目标窗口截图，不是截图基线审批。其他平台截图尚未实现；截图失败不会生成通过证据。
- 日常应用与调试实例的数据、插件和凭据命名空间由源码边界隔离；未对用户日常应用数据进行读写验收。
- macOS、Windows、Linux 的源码检查与桌面宿主编译均通过[三平台 CI](https://github.com/TunneldeDev/TunneldeDebugger/actions/runs/45490467265)。Windows/Linux 的实际窗口交互与人工视觉验收仍未验证；本版本无安装包或 Release 发布。

窗体偏移修复：设置分组定位只滚动内容区，避免 `scrollIntoView` 连带滚动应用外壳。主仓库 `pnpm check` 的 390 文件 / 3,160 用例通过；Debugger `pnpm check`、69 项 Chromium 回归及 6 项 WebKit 相关回归通过，覆盖适应窗口、50%／100%／125% 缩放、分类切换、检查器开关、画布移动及滚动截图。移除修复后，新增对齐测试会检测到应用外壳偏移并失败。新目标使用 `integration/base.json` 中包含修复的上游版本；本轮未重复执行原生窗口人工验收。
